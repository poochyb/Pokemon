# Pokémon TCG Projects

The owner is new to coding. Explain things in plain language and give click-by-click steps for anything they must do themselves.

## Apps (plain HTML/CSS/JS, no build step)
- `index.html`: **Artist Binder** (page title "PYB’s TCG Collection"), the main app. Self-contained single file. Uses the TCGdex API (https://api.tcgdex.net/v2). Tracks owned cards per illustrator, shows market prices and owned totals. Data lives in browser localStorage (key `artistBinder.v1`), with JSON backup/restore. A **Share** button makes a view-only snapshot link (`#share=` + deflate-raw/base64url JSON of artists and owned ids); opening it never writes to the viewer's localStorage. Share and Backup buttons live in the footer; the top-right of the header shows the binder total (value + owned count).
  - Categories (`state.cat`): **Artists** (sub-tabs = artists, `state.artists`/`state.active`), **Pokémon** (sub-tabs = Pokémon the owner adds, `state.pokemon`/`state.activePoke`; cards from `GET /v2/{lang}/cards?name=<longest word>` filtered by `isCardOf` so "Mew" excludes "Mewtwo" and "Porygon" excludes "Porygon-Z"; name suggestions from `pokemon-names.json`, built once from PokeAPI's `pokemon_species_names.csv`), and **EX / Mega EX** (a single sub-tab "EX" with every EX/ex card; `state.exSub` is always "all"). EX cards come from `GET /v2/en/cards?name=*EX` and `?name=*ex` (merged by id), kept if the name ends in ` EX`/`-EX`/` ex` (all eras: 2003–07 ex, 2012–16 EX, 2023+ ex, Mega ex). Owned flags are shared across categories (same `lang:id` key).
  - **Full Arts** category (`state.cat = "fa"`, one tab): a hand-picked list in `state.fullArts` (replaced the old automatic S.I.R. rarity tabs). In this category the header box becomes "Add a card…": it searches `GET /v2/{lang}/cards?name=` (a trailing number like "Wobbuffet 203" filters by card number), shows results in `#picker`, and Add stores the card's basics plus, when the card has several `variants_detailed`, the chosen version (`vid`, `vlabel` e.g. "Holo · Pokémon Center stamp", `tp` = TCGplayer product id). Adding marks the card owned. `priceOf` uses the chosen version everywhere: `prices.json` `ids[tp]` (exact TCGplayer price) first, then that version's TCGdex price.
  - **Master Sets** (`state.cat = "ms"`, tabs = `state.masterSets` `{name, groups:[TCGplayer groupIds]}`, `state.activeMs`): a checklist of every card × every printing TCGplayer sells, from `sets/<groupId>.json` (written by the daily price job: `{id, name, cards:[{p: productId, n, num, r: rarity, s: {Normal|Holofoil|Reverse Holofoil|…: price}}]}`) and `sets/index.json` (all groups, for the "Add a set…" suggestions). Adding a set also adds groups whose name starts with it (Trainer Gallery, Classic Collection…). Entries are keyed `tcgp:<productId>~<printing>` (separate from TCGdex card keys). `linkToTcgdex` matches each TCGplayer set to its TCGdex set by name ("30th Celebration" → `30th`, "…Classic Collection" → `30th-c`) and each card's first printing by number, else by unique name (Classic Collection keeps old numbers like 58/102), storing `c.link` = the TCGdex key (`setMatch` halves the score when a word with digits like "30th" is missing, so the Classic Collection doesn't tie with 2021's "Celebrations Classic Collection"). If TCGdex doesn't answer, links from the cached list are reused and linking retries every minute; `linkFromKnown()` (run on every render) also links by set name + card number to cards the app already knows (Full Arts entries, loaded tabs), so a card is never counted twice in totals. Ownership always goes through `isOwned`/`setOwned` (both keys) and `idKey` (one key per physical card, so totals count it once, using whichever copy has a price), pictured with `tcgplayer-cdn.tcgplayer.com/product/<id>_200w.jpg`, and priced from the set file. Starts with 30th Celebration (groups 24722 + 24837 Classic Collection: 191 cards, all holo only). Sets the owner asks for are added once via `SEED_SETS`/`seedMasterSets()`; `state.seeded` (names already added, so removing a tab sticks) is in backups and the cloud copy (merged on restore, left out of the change hash; a sync pushes when the cloud copy lacks some). With cloud backup on, seeding waits until after the first `cloudSync()` so another device can't bring back a removed set. Seeded so far: Chaos Rising (24655, 198 entries) and Shiny Vault (2781 Shining Fates + 2594 Hidden Fates Shiny Vaults + `"23353:92-223"` Paldean Fates shinies, 348 cards; "SV039"-style numbers sort by their digits) so far. A group may be `"<groupId>:<lo>-<hi>"` (only those card numbers; parsed in `loadMasterSet`). A `SEED_SETS` entry with a third value (tab name) adds its groups to that existing tab instead of making a new one. If the cloud copy and this device made the same change, `cloudSync` treats it as no conflict. A new set's file appears after the next daily run (or run prices.yml with `only_groups`).
  - **Most valuable** (`state.cat = "top"`): opened by clicking the binder total (top right). Every owned card from every loaded list, each once (cards carry their own `lang`), ranked by price; no Owned/Missing switch or sort menu. Above the ranked cards, `renderInsights()` shows a **Collection analysis**: KPI tiles (value, cards, average, top-N share), **collection value over time** (`drawPortfolio`: the currently owned cards' daily prices from `history/`, last price carried forward, before a card's first price its first price is assumed; same range buttons as the pop-up), and bar breakdowns by category / artist tab / Pokémon tab / set, rankable by count or value. Charts are drawn at the container's real pixel width (`drawLineChart`).
  - Sub-tabs show only the name (title tooltip has "x of y owned (N%)"; the open tab's numbers are in the toolbar); artist/Pokémon tabs can be reordered by dragging (pointer events; touch needs a 350 ms press-and-hold so swipes still scroll). The order is the array order in `state.artists` / `state.pokemon`. « » arrows appear when the tab strip overflows. Single-tab categories (EX, Full Arts, Most valuable) hide the tab row entirely (`body.no-tabs`).
- `collection.html` + `app.js` + `style.css`: older **Collection Tracker** using the Pokémon TCG API (pokemontcg.io).

- Card pictures: TCGdex `image` + `/low.webp` / `/high.webp`. TCGdex has no images for some cards (e.g. all Trainer/Galarian Gallery cards); for English ones `cardImages()` falls back to `https://images.pokemontcg.io/<set>/<num>.png` (`_hires.png` for zoom), mapping TCGdex set ids (`swsh12.5gg` → `swsh12pt5gg`, `sv03.5` → `sv3pt5`) and stripping leading zeros from numeric card numbers. Failed images show the "No image yet" box.

- Card lists are cached in localStorage (`artistBinder.lists.v1`, separate from user data). If TCGdex fails (it has short outages, e.g. HTTP 503 "no available server"), `useSaved()` shows the saved copy with a note and retries every minute; never-loaded lists show an error and keep retrying.
- TCGdex also returns Pokémon TCG Pocket (phone game) cards (`/tcgp/` images, set ids like `A4`, `B2`, `P-A`); `isPhysical()` drops them from every list.

- **Card versions** ("Your version:" menu in the price pop-up, for cards with several TCGdex `variants_detailed`): `state.versions[cardKey] = variantId` (Full Arts entries keep their own `vid/vlabel/tp`); `chosenVersion(k)` reads either. `keepDetails` stores `state.prices[k].vs` (`[{id, l: label, ty: type, tp}]`) and `mt` (main version's type); details cached before this are looked up once when the pop-up opens. `versionPrice` prices a version from `printings/NN.json` by type (`PRINTING_OF`: normal → Normal/Unlimited, holo → Holofoil/Unlimited Holofoil, reverse → Reverse Holofoil/Holofoil (e-card reverse holos are "Holofoil" on TCGplayer), firstEdition → 1st Edition…), else `ids[tp]` when the version has its own product, else TCGdex's per-version price. "Not sure" = the main version. Versions are in backups (`versions`) and share links (`w`). Tiles show the chosen version's label.
- **Cloud backup** (Backup ▾ → Cloud backup…): a secret GitHub gist (`pyb-tcg-collection.json`, the backup format plus `savedAt`) via a classic token with only the `gist` scope, pasted once per device (setup link pre-fills `scopes=gist`). Token, gist id, last-synced `savedAt` and a hash of the collection live in localStorage `artistBinder.cloud.v1` (never in backups/shares). `cloudSync()`: load the cloud copy if only it changed, save this device's if only it changed (3 s after a real collection change, `cloudSoon`; price-cache saves don't count), ask if both changed (the losing copy is kept as a gist revision). Runs at start and on tab visibility changes. Connecting on a new device reuses the existing gist (found by file name). Footer shows "☁️ Cloud backup: saved …" or a problem (bad token → re-setup).
- Clicking a card: missing → becomes owned (one click). Owned (or any card in a shared view) → **price history pop-up** (`#priceDlg`): today's price, change over a range (1W/1M/3M/6M/1Y/All), an SVG line chart with hover tooltip, and Cardmarket 1/7/30-day averages (`state.prices[k].cm`). Unmarking is the "I don't have this card" link inside it; unmarking and removing from Full Arts show an 8-second Undo bar (`showUndo`).
- Price history: `history/NNN.json` (NNN = TCGplayer productId % 1000, `{start, p: {productId: [one price per day]}}`), built daily by `scripts/build-history.mjs` from our own prices.json snapshots (backfilled from git history; starts 2026-10-10). TCGCSV's public archive is offline (HTTP 403), so there is no older history. Chart colors: `--chart` #B57F12 light / #BC8722 dark (validated with the dataviz palette script).

## Prices
- Price order in `priceOf`: (0) master-set entries use their own price; (1) the chosen version (`versionPrice`, see Card versions); (2) the card's main TCGplayer listing (`state.prices[k].tp`, from TCGdex `variants_detailed[].thirdParty.tcgplayer`: holo > normal > reverse, unstamped, standard size) → `ids` (fresh daily; TCGdex's own TCGplayer copy can be days old), priced by its printing via `printings/`; (3) TCGdex `pricing` (TCGplayer USD, else Cardmarket EUR; often `null`; a price TCGdex only has for the reverse holo is flagged `rev` and loses to (4)); (4) name/number matching below.
- `ids` holds one price per TCGplayer product, from the common printing (`PREFERRED`: Normal, Unlimited, Holofoil, Unlimited Holofoil, 1st Edition…, Reverse Holofoil last). Products sold in several printings also go to `printings/NN.json` (NN = productId % 100, `{productId: {printing: price}}`), loaded by the app only for the cards it shows.
- Fallback for English cards: `prices.json`, built daily by `.github/workflows/prices.yml` running `scripts/build-prices.mjs`, which downloads TCGplayer prices from TCGCSV (https://tcgcsv.com, category 3). It also writes `ids` (TCGplayer productId → price) for exact versions. The app matches by normalized card number + name, then best set-name overlap. Keep `normNum`/`normName` identical in both files.
- The workflow commits `prices.json` to the branch daily, so always `git pull` before pushing. It skips the TCGCSV download if prices.json is under 20 hours old (TCGCSV asks for at most one fetch per day; `FORCE_PRICES=1` overrides) and rebases on top of a newer push instead of failing.
- Japanese cards aren't covered by the fallback yet (TCGplayer category 85 uses English names; TCGdex `ja` names are Japanese).
