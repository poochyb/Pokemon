## Apps (plain HTML/CSS/JS, no build step)
- `index.html`: **Artist Binder** (page title "PYB’s TCG Collection"), the main app. Self-contained single file. Uses the TCGdex API (https://api.tcgdex.net/v2). Tracks owned cards per illustrator, shows market prices and owned totals. Data lives in browser localStorage (key `artistBinder.v1`), with JSON backup/restore. A **Share** button makes a view-only snapshot link (`#share=` + deflate-raw/base64url JSON of artists and owned ids); opening it never writes to the viewer's localStorage. With cloud backup on, Share instead gives a **short link** `#s=<gistId>` to a second secret gist (`pyb-tcg-share.json`, same JSON as `#share=` with `c: "home"`), found/created by `shortShareLink()` and re-saved by `updateShareGist()` after every `cloudSync()` (skipped when `shareHash` is unchanged; id + hash in `cloud.share`/`cloud.shareHash`). Viewers read it with an unauthenticated `GET api.github.com/gists/<id>` (`readShortShare`), so the link never changes and always shows the current collection. The header title `#homeBtn` is the **holo card logo** (inline SVG `.logo-mark`: tilted rainbow-holo card + sparkle, ids `logoHolo`/`logoShine`/`logoClip`; stacked wordmark `.logo-t1` "PYB’s" / `.logo-t2` "TCG COLLECTION"); the same card (no shine) is the SVG data-URI favicon on index.html. Share and Backup buttons live in the footer; the top-right of the header shows the binder total (value + owned count).
  - Categories (`state.cat`): **Artists** (sub-tabs = artists, `state.artists`/`state.active`), **Pokémon** (sub-tabs = Pokémon the owner adds, `state.pokemon`/`state.activePoke`; cards from `GET /v2/{lang}/cards?name=<longest word>` filtered by `isCardOf` so "Mew" excludes "Mewtwo" and "Porygon" excludes "Porygon-Z"; name suggestions from `pokemon-names.json`, built once from PokeAPI's `pokemon_species_names.csv`). **Spelling help:** on Add, a name matching a known one apart from capitals/accents/spaces takes its spelling (`exactName`, from `pokemon-names.json` or TCGdex illustrators); when a Pokémon tab loads, `fixPokeSpelling` copies the capitals printed on its cards ("misty" → "Misty", moving its keys). A name with no cards (`mem.notFound`) shows "Did you mean…?" buttons (`closeNames`, edit distance) that rename the tab (`renameTab`), and **EX / Mega EX** (a single sub-tab "EX" with every EX/ex card; `state.exSub` is always "all"). EX cards come from `GET /v2/en/cards?name=*EX` and `?name=*ex` (merged by id), kept if the name ends in ` EX`/`-EX`/` ex` (all eras: 2003–07 ex, 2012–16 EX, 2023+ ex, Mega ex). Owned flags are shared across categories (same `lang:id` key).
  - **Chase Cards** category (shown as "Chase Cards"; internally still `state.cat = "fa"`, `FA_LIST`, `state.fullArts`, so backups/shares stay compatible; one tab): hand-picked entries in `state.fullArts` **plus** `autoChase()`: every owned card from any other list whose rarity `isChase()` accepts (Full Art Trainer, Illustration Rare, Special Illustration Rare, Mega Attack Rare, Hyper Rare, Mega Hyper Rare, and Ultra Rare only when numbered above the set size, e.g. 108/088, using `state.details[k].o` = TCGdex `set.cardCount.official` or TCGplayer's "n/total"), or any owned card priced above `CHASE_MIN_USD` = $20 (`pricedOver`, via `priceOf`; the owner's choice). Automatic cards carry `auto: true` (no Remove button, skipped by `fillDetails`). In this category the header box becomes "Add a card…": it searches `GET /v2/{lang}/cards?name=` (a trailing number like "Wobbuffet 203" filters by card number), shows results in `#picker`, and Add stores the card's basics plus, when the card has several `variants_detailed`, the chosen version (`vid`, `vlabel` e.g. "Holo · Pokémon Center stamp", `tp` = TCGplayer product id). Adding marks the card owned. `priceOf` uses the chosen version everywhere: `prices.json` `ids[tp]` (exact TCGplayer price) first, then that version's TCGdex price.
  - **Master Sets** (`state.cat = "ms"`, tabs = `state.masterSets` `{name, groups:[TCGplayer groupIds]}`, `state.activeMs`): a checklist of every card × every printing TCGplayer sells, from `sets/<groupId>.json` (written by the daily price job: `{id, name, cards:[{p: productId, n, num, r: rarity, s: {Normal|Holofoil|Reverse Holofoil|…: price}}]}`) and `sets/index.json` (all groups, for the "Add a set…" suggestions). Adding a set also adds groups whose name starts with it (Trainer Gallery, Classic Collection…). Entries are keyed `tcgp:<productId>~<printing>` (separate from TCGdex card keys). `linkToTcgdex` matches each TCGplayer set to its TCGdex set by name ("30th Celebration" → `30th`, "…Classic Collection" → `30th-c`) and each card's first printing by number, else by unique name (Classic Collection keeps old numbers like 58/102), storing `c.link` = the TCGdex key (`setMatch` halves the score when a word with digits like "30th" is missing, so the Classic Collection doesn't tie with 2021's "Celebrations Classic Collection"). If TCGdex doesn't answer, links from the cached list are reused and linking retries every minute; `linkFromKnown()` (run on every render) also links by set name + card number to cards the app already knows (Full Arts entries, loaded tabs), so a card is never counted twice in totals. Ownership always goes through `isOwned`/`setOwned` (both keys; a TCGdex card also checks master-set entries linked to it via `linkedFrom()`, so a card ticked in a master set before its link existed still shows owned in Pokémon/artist tabs). **Any printing counts** (the owner's rule): a TCGdex card in a Pokémon/artist/EX/Chase tab also shows owned when *any* master-set printing of it (same TCGplayer product: regular, holo, reverse holo…) is ticked (`allPrintingsOf`/`otherPrintingOwned`); its `idKey` is then that printing's key so totals count the physical card once (and `keepFirstPriced` prefers the master-set copy, `_ms`, for that printing's price). Marking a tab card owned still ticks only its own/first printing; "I don't have this card" clears every printing, and Undo restores exactly the keys `setOwned` returns and `idKey` (one key per physical card, so totals count it once, using whichever copy has a price), pictured with `tcgplayer-cdn.tcgplayer.com/product/<id>_200w.jpg`, and priced from the set file. Starts with 30th Celebration (groups 24722 + 24837 Classic Collection: 191 cards, all holo only). Sets the owner asks for are added once via `SEED_SETS`/`seedMasterSets()`; `state.seeded` (names already added, so removing a tab sticks) is in backups and the cloud copy (merged on restore, left out of the change hash; a sync pushes when the cloud copy lacks some). With cloud backup on, seeding waits until after the first `cloudSync()` so another device can't bring back a removed set. Seeded so far: Chaos Rising (24655, 198 entries) and Shiny Vault (2781 Shining Fates + 2594 Hidden Fates Shiny Vaults + `"23353:92-223"` Paldean Fates shinies, 348 cards; "SV039"-style numbers sort by their digits) so far. A group may be `"<groupId>:<lo>-<hi>"` (only those card numbers; parsed in `loadMasterSet`). A `SEED_SETS` entry with a third value (tab name) adds its groups to that existing tab instead of making a new one. If the cloud copy and this device made the same change, `cloudSync` treats it as no conflict. A new set's file appears after the next daily run (or run prices.yml with `only_groups`).

## Prices
- Price order in `priceOf`: (0) master-set entries use their own price; (1) the chosen version (`versionPrice`, see Card versions); (2) the card's main TCGplayer listing (`state.prices[k].tp`, from TCGdex `variants_detailed[].thirdParty.tcgplayer`: holo > normal > reverse, unstamped, standard size) → `ids` (fresh daily; TCGdex's own TCGplayer copy can be days old), priced by its printing via `printings/`; (3) TCGdex `pricing` (TCGplayer USD, else Cardmarket EUR; often `null`; a price TCGdex only has for the reverse holo is flagged `rev` and loses to (4)); (4) name/number matching below.
- `ids` holds one price per TCGplayer product, from the common printing (`PREFERRED`: Normal, Unlimited, Holofoil, Unlimited Holofoil, 1st Edition…, Reverse Holofoil last). Products sold in several printings also go to `printings/NN.json` (NN = productId % 100, `{productId: {printing: price}}`), loaded by the app only for the cards it shows.
- Fallback for English cards: `prices.json`, built daily by `.github/workflows/prices.yml` running `scripts/build-prices.mjs`, which downloads TCGplayer prices from TCGCSV (https://tcgcsv.com, category 3). It also writes `ids` (TCGplayer productId → price) for exact versions. The app matches by normalized card number + name, then best set-name overlap. Keep `normNum`/`normName` identical in both files.
- The workflow commits `prices.json` to the branch daily, so always `git pull` before pushing. It skips the TCGCSV download if prices.json is under 20 hours old (TCGCSV asks for at most one fetch per day; `FORCE_PRICES=1` overrides) and rebases on top of a newer push instead of failing.
- **No euros on screen:** `priceOf` wraps `priceInAnyCurrency` and converts any EUR price to USD with `toUSD` (keeps the original as `p.eur`) at `fx.rate`: `fx.json` (`{eurUsd, date}`, ECB rate saved daily by `scripts/build-fx.mjs` in prices.yml via Frankfurter, ECB XML as backup) or, if newer, the browser's live `api.frankfurter.dev/v1/latest?base=EUR&symbols=USD`; `FX_FALLBACK` until either answers. Cardmarket averages in the pop-up are converted too. The owner wants plain USD: no "converted from euros" or rate text anywhere.
- Japanese cards aren't covered by the fallback yet (TCGplayer category 85 uses English names; TCGdex `ja` names are Japanese).
