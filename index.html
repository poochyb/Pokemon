    Cloud backup

    Save your collection to your GitHub account automatically, every time you change something. It stays safe if this browser’s data is cleared, and your phone and computer can share the same collection. Every save is kept, so older versions can be recovered.

    One-time setup (about 2 minutes):

    1. Open GitHub’s “New token” page (sign in if asked). The name and the gist box are already filled in.
    2. Under Expiration, choose No expiration (or pick a date; you’ll repeat this setup when it runs out).
    3. Scroll to the bottom and click Generate token.
    4. Copy the token (it starts with ghp_) and paste it here:

    The token only lets this app create and update gists (small notes in your GitHub account). It’s kept in this browser only. Your backup is a secret gist: it isn’t listed or searchable, but anyone with its exact link could open it (it holds the same information as your Share link).

    Older versions

    On another device (like your phone): open this site there, choose Backup ▾ → Cloud backup…, and paste the same token (or make a new one the same way). To bring back an older version: open Older versions, find the one you want, click Raw, save that page as a file, then use Backup ▾ → Restore backup.
